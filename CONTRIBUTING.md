# Contributing to Summond

Thanks for your interest in improving Summond. Contributions are welcome.

## Development setup

- macOS 26.0+
- [XcodeGen](https://github.com/yonaskolb/XcodeGen) 2.45+ (`brew install xcodegen`)
- Xcode 26+

`Summond.xcodeproj` is generated by XcodeGen and is not committed. Run
`make project` after cloning and whenever `project.yml` or the file layout
changes.

## Before opening a pull request

Run the checks that CI runs:

```bash
make lint        # swift-format lint (strict)
make core-test   # SummondCore package tests
make app-test    # app unit tests (swift-testing)
```

`make test` runs the core and app tests together. Keep the diff focused, match
the surrounding style, and add or update tests for behavior you change.

## UI and VM tests

The XCUITest UI suite drives a real GUI with injected or faked services. The
unattended launchctl/XPC smoke exercises real launchd and mach-service XPC.
Both run in a disposable [Tart](https://tart.run/) VM rather than in CI:

```bash
make test-tart   # unit + UI tests in a clean VM
make smoke-tart  # launchctl spawn + mach-service XPC round-trip
```

These are maintainer-run and are not required for a pull request.

## Scope

Summond relies on private SkyLight window-server functions for current-Space
membership queries in **New Window** and for **Move Here** (see the private-API
note in the README). Changes there should keep the runtime symbol resolution
and graceful-degradation behavior intact.
